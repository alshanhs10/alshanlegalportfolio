# Alshan Husain Shah — Legal Portfolio

Professional single-page legal portfolio showcasing legal education, practical experience, certifications, projects, publications and professional achievements.

## Files

- `index.html` — website content and structure
- `style.css` — visual design, responsive layout and animations
- `script.js` — navigation, scroll reveal, image viewer and PDF viewer
- `assets/` — certificates, project documents, awards and resume
- `favicon.png` — website favicon and AHS brand mark

## Assets

### Certificates
Certificate images are stored in `assets/certificates/` and referenced by the corresponding certificate cards in `index.html`.

### Projects
Project documents are stored in `assets/projects/`.

### Awards
Award images are stored in `assets/awards/`.

### Resume
The current resume is stored at:

`assets/Alshan_Husain_Shah_Resume.pdf`

## Publications

Publication entries contain links to their respective articles and publication pages.

## Important

Only publish non-confidential legal work, documents and materials that you are permitted to make publicly available.

## Accessibility & Performance

The website includes responsive layouts, accessible interactive elements and `prefers-reduced-motion` support.

## Deployment

This is a static HTML/CSS/JavaScript website and can be hosted using GitHub Pages or another static hosting service.
